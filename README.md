# The Hush

The Hush is a short, wordless browser game: a vector metroidvania set in a silent kingdom, where every room you clear brings back one layer of the music until the whole song plays again. It is built to run in a desktop browser, with a keyboard, at https://jhonalbert.com/hush/. The source is free software under the GNU Affero General Public License, version 3 or (at your option) any later version (see LICENSE); the music engine is Strudel, also AGPL-3.0-or-later. Built with Phaser 4, Strudel and TypeScript.
